# Stylish Calculator

A responsive and visually appealing calculator built with HTML, CSS, and JavaScript. Designed with a soft lavender/purple gradient background and smooth button styling for an elegant user experience.

## ✨ Features

- Basic arithmetic operations: addition, subtraction, multiplication, division, modulus
- Responsive layout
- Stylish UI with gradients and custom hover effects
- Animated background and themed buttons

## 🧰 Tech Stack

- HTML
- CSS (custom styles with gradient and animations)
- JavaScript (basic calculator logic using `eval()`)

## 📦 Folder Structure

```

/calculator
├── index.html      # Main HTML structure
├── style.css       # Styling and layout
└── script.js       # Calculator logic

```

## 🚀 How to Run

1. Download or clone the repository.
2. Open `index.html` in your browser.
3. Use the calculator on any modern device.

## ⚙️ Functionality

- **appendValue(value):** Adds the clicked number/operator to the display
- **clearDisplay():** Clears the input display
- **calculate():** Evaluates the expression and shows the result
